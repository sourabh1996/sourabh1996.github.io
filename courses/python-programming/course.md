# Python Programming

**Beginner · 10 modules · 38 lessons · ~18 hrs**  
Track 1 · Programming Foundations · Bootcamp syllabus module(s): 1, 2

Learn Python from zero to confident: values, control flow, collections, functions, classes, files, modules, errors and async code.

**Finish first:** [The Command Line and Linux Basics](../the-command-line-and-linux-basics/course.md)  
**Unlocks:** [Git and GitHub: Zero to Pro](../git-and-github-zero-to-pro/course.md), [Data Analysis and Visualisation with Python](../data-analysis-and-visualisation-with-python/course.md), [Databases: SQL and NoSQL](../databases-sql-and-nosql/course.md), [APIs and Apps: FastAPI, Streamlit and Docker](../apis-and-apps-fastapi-streamlit-and-docker/course.md)
